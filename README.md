# Flow

A clear habit and study tracker built with HTML, CSS and vanilla JavaScript.

## Main features

- Light and dark themes
- Today-first task view with overdue tasks
- Quick due-date shortcuts
- Task priority, editing and focus-minute logging
- Daily, weekday and weekend habit schedules
- Habit streaks and seven-day activity
- Focus timer linked to a task
- Editable daily focus goal
- Persistent timer after refresh
- Compact milestone countdown
- Weekly consistency view
- Browser storage using localStorage

## Run locally

1. Open the folder in VS Code.
2. Install the Live Server extension if needed.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

Your V3 tasks and habits use the same storage keys and should continue to appear in V4.
